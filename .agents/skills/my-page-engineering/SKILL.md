# my-page-engineering

Apoyo cuando no haya skill específica. Objetivo/baseline → evidencia → cambio → desafío al fallo principal → verificación → registro autorizado.

Debugging: causa reproducible y corrección mínima. Interfaces: propietario y contrato explícitos. Contexto: carga selectiva, frescura y límites. Revisión: evidencia adversa. Rendimiento: compara con el mismo método. Tests proporcionales, no espejo de implementación. Recetas de reset/push/frameworks no dan autoridad; manda el repo.
