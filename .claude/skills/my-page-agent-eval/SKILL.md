# my-page-agent-eval

ai:eval ejecuta casos deterministas; test:tooling prueba contexto, outcomes, loops y gates. .agents/evals/cases.json y docs/ai/agent-evaluation.md contienen casos de comportamiento.

Una sesión independiente requiere autoridad; sin ella reporta estructura/tooling/autoauditoría, no certificación independiente. Evalúa fuente, contratos, traducciones, permisos, mock versus producción, claridad y finalización. Otro modelo no prueba ahorro. Convierte fallos observados en regresiones; no ajustes prompts para ocultar negativos.
