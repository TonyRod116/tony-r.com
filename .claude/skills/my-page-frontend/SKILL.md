# my-page-frontend

Lee .agents/design-context.md y docs/ai-skills/browser-qa.md. Usa identidad propia, imágenes reales, jerarquía y acciones comprensibles. Comprueba móvil/escritorio, teclado/foco, textos largos, ES/EN/CA y movimiento reducido.

Ejecuta check:design, test:e2e, test:visual y perf:report cuando apliquen. La captura no prueba interacción; build no prueba navegación.
