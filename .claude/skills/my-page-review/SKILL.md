# my-page-review

Contrasta baseline, código y consumidores. Ordena hallazgos por corrección, seguridad/datos, contratos, tests, accesibilidad, rendimiento y simplicidad. Incluye archivo, evidencia, impacto y corrección. Busca el fallo que el camino feliz oculta.

Autoauditoría no es revisión independiente. Otro modelo solo con petición/autoridad de Tony y skill vigente del proveedor. ai:route -- --mode review solo planifica; nunca copia runners, manda código o cambia facturación. Detalles en docs/ai/review-and-loops.md.
