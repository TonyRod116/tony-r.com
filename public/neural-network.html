1

Input Layer

Each 28×28 pixel drawing is flattened into a vector of 784 numbers. This is the entry point of the network.

2

Dense(64, relu)

A Dense (fully connected) layer: every one of the 64 neurons receives input from ALL 784 pixels. "Dense" means every possible connection exists. ReLU activation: if the value is negative → 0, if positive → passes through unchanged.

3

Dense(32, relu)

Second hidden layer with 32 neurons, each connected to all 64 neurons from the previous layer. The network learns progressively more abstract patterns at each layer.

4

Dense(10, softmax)

10 output neurons — one for each digit (0–9). Softmax converts raw scores into probabilities that sum to 1.0, so the network effectively "votes" on which digit it sees.

5

Compile

Configures how the model learns. The loss function (SparseCategoricalCrossentropy) measures how wrong predictions are. Adam is an optimizer that adjusts weights to minimize that error.

6

Train

The model sees the entire dataset 40 times (epochs). Each pass: it makes predictions, measures the error, and updates its weights to improve.

How the model learns during training

A simple view of the update rule behind better predictions

Update Rule

$$w_{t+1} = w_t - \eta \nabla_w L(w_t),\quad b_{t+1} = b_t - \eta \nabla_b L(b_t)$$

At each step, we move parameters in the opposite direction of the gradient to decrease loss.

Learning Rate

η too low → slow learning · η too high → instability

The learning rate controls step size. Too low converges slowly; too high can overshoot and diverge.

Linear Regression Example

$$J(\theta)=\frac{1}{2m}\sum_{i=1}^{m}(h_\theta(x^{(i)})-y^{(i)})^2,\quad \theta:=\theta-\eta\nabla_\theta J(\theta)$$

The same descent idea appears in linear models: minimize a cost, compute gradient, update parameters.

Logistic Regression Example

$$\hat{y}=\sigma(\theta^\top x),\quad J(\theta)=-\frac{1}{m}\sum_{i=1}^{m}\left[y^{(i)}\log\hat{y}^{(i)}+(1-y^{(i)})\log(1-\hat{y}^{(i)})\right]$$

In logistic regression we optimize cross-entropy with gradient descent to improve binary predictions.

Why models can memorize too much

What overfitting means and the main tools used to reduce it

What is overfitting?

Overfitting happens when the model gets too attached to the training examples. It performs well on familiar data but worse on new drawings it has never seen.

L2 Regularization (Weight Decay)

$$L = L_{\text{data}} + \lambda \lVert w \rVert_2^2$$

Penalizes large weights, making the model smoother and less sensitive to noise.

L1 Regularization

$$L = L_{\text{data}} + \lambda \sum_i |w_i|$$

Promotes sparse weights: many become 0, which can simplify the model.

Dropout

$$\tilde{h} = m \odot h,\quad m \sim \mathrm{Bernoulli}(1-p)$$

Randomly drops units during training so neurons cannot co-adapt too much.

Early Stopping

Stop training when validation loss stops improving for several epochs (patience).

How to prevent overfitting

  1. Use a validation set and monitor validation loss.
  2. Apply L2 regularization and tune lambda.
  3. Use dropout in hidden layers.
  4. Use early stopping with patience.
  5. Prefer simpler architectures when possible.

Dense layer

A dense layer connects every input to every neuron in the next layer. That gives the model flexibility, but it also means more values to learn.

ReLU activation

ReLU is a simple filter: negative values become 0, positive values keep going. This helps the network keep useful signals and ignore weaker ones.

Probability output

Softmax turns raw scores into probabilities. The class with the highest probability becomes the model's prediction.

Key Concepts

Dive deeper into the building blocks

Weights are the learnable numbers on every connection between neurons. Each weight controls how much influence one neuron has on the next. Biases give each neuron an adjustable threshold — they shift the activation function left or right. Together, weights and biases are the "knowledge" the network acquires during training.
Sparse Categorical Crossentropy measures how far the predicted probabilities are from the true label. If the correct digit is 7 and the model gives 90% confidence to 7, the loss is low. If it gives 10%, the loss is high. The goal of training is to minimize this number across all examples.
Adam (Adaptive Moment Estimation) is a smart version of gradient descent. It maintains a moving average of both the gradients and their squared values, adapting the learning rate for each weight individually. This makes training faster and more stable than basic gradient descent.
One epoch means the model has seen every training example once. Training for 40 epochs means the model passes over the full dataset 40 times. With each pass, it refines its weights — but too many epochs can lead to overfitting, where the model memorizes training data instead of learning general patterns.
ReLU is the default in hidden layers. Leaky ReLU helps avoid dead neurons. Sigmoid is common for binary output. Tanh is zero-centered. GELU is frequent in transformers. Softmax is used for multiclass output.
Use three checks: which bar is highest, how clearly it leads, and whether your drawing looks clean. If several bars are close, the model is unsure.
If the prediction is wrong: 1) center the digit, 2) avoid very thick strokes, 3) remove extra marks, 4) check whether several bars are close, 5) try again with a cleaner shape.
